# 📊 COVID-19 Global Analysis Dashboard

This project presents an interactive COVID-19 data analysis dashboard built using Power BI.

## 🔍 Overview
The dashboard analyzes COVID-19 trends across multiple countries, focusing on:
- Total cases, deaths, and recoveries
- Vaccination rates
- Time-series trends

## 🛠️ Tools Used
- Power BI
- Excel

## 📈 Key Insights
- COVID-19 cases show clear peaks and declines over time
- Recovery rates are significantly higher than death rates
- Vaccination rates vary across countries

## 📂 Files in this Repository
- `COVID-19 ANALYSIS.pbix` → Power BI Dashboard
- `COVID19_100plus_Unique.xlsx` → Dataset
- `Screenshot.png` → Dashboard Preview
